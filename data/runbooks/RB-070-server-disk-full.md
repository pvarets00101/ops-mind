# Заканчивается место на диске сервера

## Пороги мониторинга
- **Warning** — заполнено 85% раздела.
- **Critical** — заполнено 95% раздела, автоматически создаётся обращение P2 (для продуктивных серверов — P1, если сервис деградировал).

## Диагностика (Linux)
```bash
df -h
du -xh / --max-depth=2 2>/dev/null | sort -rh | head -20
lsof +L1   # удалённые, но открытые файлы
```
## Диагностика (Windows)
WinDirStat или `Get-ChildItem C:\ -Recurse | Sort Length -Desc | Select -First 20`.

## Типовые причины и решения
| Причина | Решение |
|---|---|
| Разросшиеся логи приложения | Проверить logrotate (`/etc/logrotate.d/`), хранить не более 14 дней |
| Удалённый, но открытый лог | Перезапустить процесс в согласованное окно или `truncate` файла |
| Docker-образы и тома | `docker system prune -a` только на непродуктивных серверах |
| Рост данных | Расширение диска |

## Расширение диска
Диски виртуальных машин расширяются в vCenter (`vcenter.corp.local`) без остановки ВМ, затем раздел расширяется в ОС. Расширение более чем на 500 ГБ согласовывается с руководителем Infra (лимит СХД).
