# VPN-доступ для подрядчика

## Условия
- Доступ выдаётся только по действующему договору и NDA.
- Инициатор — сотрудник компании (куратор подрядчика), он отвечает за действия подрядчика.
- Учётная запись подрядчика создаётся с префиксом `ext-` и помещается в группу `VPN-Contractors`.
- Срок доступа — **не более 90 дней**, продление — новой заявкой.
- Доступ открывается только к перечисленным в заявке подсетям и портам. Доступ «ко всей сети» не выдаётся.

## Порядок
1. Куратор создаёт заявку «VPN для подрядчика»: ФИО, компания, номер договора, срок, список систем (хост/порт).
2. Согласования: руководитель куратора → владелец системы → Security.
3. Network создаёт правило на межсетевом экране, ServiceDesk — учётную запись.
4. Срок выполнения — до **3 рабочих дней** после последнего согласования.

## Окончание доступа
За 7 дней до окончания куратор получает уведомление. В день окончания учётная запись блокируется автоматически, через 30 дней — удаляется.
