# Доступ к сетевой папке

## Как устроен доступ
- Файловые ресурсы находятся на \fs01.corp.local. Права выдаются только через группы AD, напрямую пользователю — никогда.
- Именование групп: `FS-<ресурс>-RW` (чтение и запись) и `FS-<ресурс>-RO` (только чтение).
- У каждого ресурса есть владелец (указан в каталоге ресурсов на портале).

## Порядок
1. Пользователь создаёт заявку «Доступ к сетевому ресурсу» на портале https://help.corp.local и указывает путь и тип доступа.
2. Заявку согласуют руководитель пользователя и владелец ресурса.
3. ServiceDesk добавляет пользователя в группу.
4. Права применяются после выхода из системы и повторного входа (или перезагрузки) — членство в группах обновляется только при входе.

## Частые проблемы
- «Нет доступа» сразу после выдачи прав — пользователь не перелогинился.
- Доступ к папкам с меткой «Конфиденциально» дополнительно согласует Security, срок рассмотрения — до 2 рабочих дней.
- Доступ подрядчикам к \fs01 не выдаётся, для обмена файлами используется портал https://share.corp.local.
