# Передача данных за пределы компании

## Классификация данных
| Класс | Примеры | Передача вовне |
|---|---|---|
| Публичные | Пресс-релизы, сайт | Без ограничений |
| Внутренние | Регламенты, оргструктура | Только партнёрам по NDA |
| Конфиденциальные | Договоры, финансовая отчётность, исходный код | Только с согласования Security, в зашифрованном виде |
| Персональные данные | Данные клиентов и сотрудников | Только по договору поручения обработки ПДн, с согласования Security и юриста |

## DLP
Система DLP контролирует почту, веб-загрузки и съёмные носители. Письмо с признаками конфиденциальных данных внешнему адресату задерживается до проверки Security (до 4 рабочих часов).

## Как передать конфиденциальные данные
1. Заявка «Передача данных» с указанием получателя, состава данных и основания (номер договора).
2. Согласование Security, для ПДн — дополнительно юриста.
3. Передача через https://share.corp.local (ссылка с паролем и сроком действия до 7 дней) или зашифрованным архивом AES-256, пароль — по другому каналу.

## Запрещено
Пересылать рабочие документы на личную почту, загружать в личные облака и публичные AI-сервисы.
