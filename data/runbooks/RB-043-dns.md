# Проблемы с DNS

## Инфраструктура
- Внутренние DNS-серверы: **10.10.0.10** (dns01) и **10.10.0.11** (dns02), они же контроллеры домена.
- Внутренняя зона — `corp.local`. TTL записей по умолчанию — **300 секунд**.
- Внешние запросы пересылаются на DNS провайдера.

## Симптомы
- «Не удаётся найти сервер» для внутреннего имени при работающем доступе по IP.
- Новый сервер не находится по имени.

## Диагностика
```
nslookup app01.corp.local 10.10.0.10
nslookup app01.corp.local 10.10.0.11
```
- Разные ответы от dns01 и dns02 — проблема репликации зон, сразу эскалировать в Network.
- Оба сервера отвечают правильно, а у пользователя нет — локальный кэш: `ipconfig /flushdns`.
- Проверить файл `C:\Windows\System32\drivers\etc\hosts` на ручные записи.

## Изменение записей
- Создание и изменение записей — только через заявку в Network, срок — 1 рабочий день.
- Изменение вступает в силу для всех клиентов не позже чем через TTL (5 минут) после применения.
- Записи для продуктивных сервисов меняются только в рамках изменения (change request), см. RB-102.
