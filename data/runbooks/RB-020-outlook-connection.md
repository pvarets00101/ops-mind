# Outlook не подключается к почтовому серверу

## Симптомы
- В строке состояния Outlook «Отключено» или «Попытка подключения…».
- Постоянно появляется окно ввода пароля.

## Диагностика
1. Проверить статус почты на https://status.corp.local — при массовом сбое не тратить время на рабочее место, привязать обращение к инциденту.
2. Убедиться, что веб-почта https://mail.corp.local/owa открывается под учётной записью пользователя. Если нет — проблема с учётной записью (RB-010, RB-011).
3. Проверить автообнаружение: Ctrl + правый клик по значку Outlook в трее → «Проверить автоматическую настройку электронной почты». Должен отвечать `autodiscover.corp.local`.

## Решение
1. Запустить Outlook в безопасном режиме: `outlook.exe /safe`. Если работает — отключить надстройки.
2. Удалить сохранённые учётные данные для `mail.corp.local` в Диспетчере учётных данных Windows.
3. Создать новый профиль: Панель управления → Почта → Показать → Добавить. Старый профиль не удалять до проверки.
4. Вне офиса Outlook работает только при подключённом VPN или через MFA (RB-013).

## Эскалация
Если OWA работает, а новый профиль не подключается у нескольких пользователей — передать в Infra (почтовые серверы).
