# Установка программного обеспечения

## Правила
- У пользователей нет прав локального администратора.
- Разрешённое ПО устанавливается самостоятельно через **Software Center** (Пуск → Software Center). Там же можно обновить и удалить программы.
- Каталог разрешённого ПО опубликован на https://help.corp.local/software.

## ПО не из каталога
1. Заявка «Установка ПО» с указанием названия, версии, ссылки на сайт производителя и обоснования.
2. Согласования: руководитель → Security (проверка лицензии и безопасности).
3. Срок — **3 рабочих дня**. Если ПО платное — дополнительно закупка, срок определяет отдел закупок.
4. После одобрения ПО добавляется в Software Center, а не ставится вручную.

## Запрещено
- Торрент-клиенты, средства удалённого доступа (AnyDesk, TeamViewer и аналоги), сторонние VPN, игры.
- Установка из портативных архивов в обход Software Center — нарушение политики ИБ.

## Временные права администратора
Выдаются только разработчикам по заявке с согласованием Security, на срок до 8 часов, через LAPS.
