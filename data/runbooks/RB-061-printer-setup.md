# Подключение принтера и печать FollowMe

## FollowMe — основной способ
- На всех компьютерах уже подключён принтер **FollowMe**. Задание уходит в общую очередь, а напечатать его можно на любом МФУ офиса, приложив пропуск к считывателю.
- Неотпечатанные задания хранятся **24 часа**, потом удаляются.
- Если пропуск не привязан — при первом прикладывании МФУ попросит ввести доменный логин и пароль.

## Подключение конкретного принтера
1. Win+R → `\\print01.corp.local` → двойной клик по нужному принтеру.
2. Имена принтеров имеют формат `<этаж>-<кабинет>-<модель>`, например `3-214-MFP`.
3. Драйвер устанавливается автоматически с сервера печати.

## Цветная печать
Цветная печать доступна только на МФУ с пометкой `-COLOR` и только для сотрудников из группы `Print-Color` (маркетинг, дизайн, секретариат). Другим — по заявке с согласованием руководителя.
