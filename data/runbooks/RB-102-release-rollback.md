# Релизы в продуктив и откат

## Окно изменений
- Плановые релизы в продуктив — **вторник и четверг с 10:00 до 16:00**.
- **Пятница — заморозка**: релизы запрещены, кроме исправления инцидентов P1/P2.
- Заморозка на праздники объявляется отдельно (обычно с 25 декабря по 10 января).

## Change request
- Любое изменение продуктива оформляется заявкой на изменение (change request) в портале.
- Стандартные изменения (деплой через пайплайн без миграций схемы) согласовываются автоматически.
- Нормальные изменения (миграции БД, изменения сети, инфраструктуры) — согласование CAB, заседание по понедельникам в 15:00, подача до пятницы 18:00.
- Экстренные изменения при P1 — согласование инцидент-менеджера, оформление заявки задним числом в течение 1 рабочего дня.

## Откат
1. Решение об откате принимает владелец сервиса или дежурный, если после релиза выросли ошибки или упали ключевые метрики.
2. Helm-релизы:
   ```bash
   helm history <release> -n <ns>
   helm rollback <release> <revision> -n <ns>
   ```
3. Миграции БД должны быть обратно совместимыми (expand/contract) — откат кода не должен требовать отката схемы.
4. Об откате сообщить в #releases и зафиксировать в change request.
