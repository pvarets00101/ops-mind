# Нет доступа в интернет на рабочем месте

## Как устроен доступ
- Из офисной сети в интернет можно выйти только через прокси `proxy.corp.local:3128`.
- Настройки прокси распространяются автоматически через PAC-файл `http://wpad.corp.local/wpad.dat` (групповая политика).
- Внутренние ресурсы *.corp.local открываются в обход прокси.

## Диагностика
1. Внутренние ресурсы (например, https://help.corp.local) открываются? Если нет — проблема с сетью на рабочем месте, а не с интернетом.
2. `ipconfig /all`: адрес должен быть из сети 10.20.0.0/16 (офис) и DNS 10.10.0.10 / 10.10.0.11. Адрес вида 169.254.x.x — DHCP не выдал адрес: проверить кабель и порт.
3. Проверить прокси в настройках браузера: «Использовать сценарий настройки» с адресом PAC-файла.
4. `curl -x http://proxy.corp.local:3128 -I https://ya.ru` — если ответ 407, прокси не принял учётные данные (проверить блокировку учётной записи, RB-011).

## Решение
- Неправильный PAC или ручной прокси — `gpupdate /force` и перезапуск браузера.
- Нет адреса по DHCP — переподключить кабель в другой порт, при повторении — заявка в Network с номером розетки (наклейка на розетке, формат `3-214-05`).
- Конкретный сайт не открывается, а остальные работают — см. RB-042.
